## 1. P10 v1 Positive Predicate

For primary life `L`, derive:

```text
arrival(L) = any eligible credited direction whose destination is ☷
release_events(L) = packet_trace events with type=unit_dissolution
```

The dedicated writer accepts an empty action cost. Packet trace storage
canonicalizes that boundary into the complete zero-cost vector; the reader
must verify the stored vector, not compare it with the pre-storage `{}` form.

P10 is semantically positive only when:

```text
arrival(L) = true
count(release_events(L)) = 1
release payload verifies as dissolve.inherited_rejected_form_release.v0
event.operator = ☷
event.truth_status = runtime_confirmed
target final state matches payload.after_version/after_activation
target kind = inherited_rejected_form
target generation = Packet generation
target applicability remains inherited_proposal history, now dissolved
target activation_source.event_id = release event id
residue final state matches payload.residue_unit_id
residue kind = rejected_form_residue
residue.created_event_id = release event id
residue carrier verifies and names the same release id
target carrier, release reason and residue ancestor refs agree
```

The evaluator rejects duplicate direct-treatment release events in v1. A later
multi-release protocol requires a new table decision and evaluator version.

## 3. `no_rigidity` Control v1

For every positive primary life, at least one referenced `no_rigidity` life
must satisfy:

```text
same implementation revision and physics epoch (enforced by corpus view)
same work mode
same exact chaos.raw_prompt
no live/selected inherited_rejected_form
no unit_dissolution event
no eligible credited direction ending at ☷
```

A control that merely contains a reference with the right label is red. A
consumer-ablation life belongs to supporting evidence, because ablation changes
the policy descriptor/physics epoch.

may differ; Packet physics, final field, route credit and corpse may not.
