## 0. Why This Note Exists

The body can now grow and execute one exact DISSOLVE treatment:

```text

-> NETWORK/FLOW inherited form
-> qualified blocking witness
-> credited arrival at DISSOLVE
-> unit_dissolution
-> dissolved applicability + preserved residue
-> post-release OBSERVE
```

The generic P10 corpus reader predates that treatment. It currently calls P10
green when both of these indirect facts are present:

```lua

#boundary.loss_records > 0
```

That predicate reads the wrong physical channel. `boundary.loss_records` is
the crystallization/identity-loss history. The new treatment deliberately
records:

```text

irreversible_identity_loss = 0
```

The inherited form stopped binding the child, but its historical QA evidence
survived in residue. Calling this zero-loss release unproven, or satisfying it
with an unrelated crystallization loss, confuses two conserved quantities.

## 2. Selected Physical Distinction

P10 v1 separates three facts:

| Fact | Writer | Meaning |
|---|---|---|
| route credit into ☷ | authority instrument v3 | DISSOLVE was selected and its destination tick/effect executed |
| released mass | `unit_dissolution` | exact current form ceased to bind the Packet |
| irreversible loss | release payload / loss physics | information or identity was destroyed rather than retained |

For `dissolve.inherited_rejected_form_release.v0` the accepted vector is:

```text
released_mass = {forms=1, relations=0}
irreversible_identity_loss = 0
residue = exact and runtime-confirmed
```

This does not assert that every future DISSOLVE has zero loss. It asserts that
the reader must inspect the treatment's typed accounting instead of borrowing
an unrelated loss ledger.


## 4. Negative Control

The existing control name `no_rigidity` is retained for compatibility, but its
v1 meaning becomes executable:

```text

same authority physics epoch
same work mode and exact prompt bytes as at least one primary life
no live/selected inherited_rejected_form

```

The primary observer pair remains a separate requirement. It proves that the
legacy observer has zero mass. The no-rigidity control proves that removing the
qualified fact removes the DISSOLVE effect. Neither substitutes for the other.

Consumer ablation remains useful supporting evidence, but it is not mislabeled
as a no-rigidity state: it deliberately changes policy physics while retaining
the form.

## 8. Red-Test Finding: Expected Deferral Is Not Unqualified Physics

The first grown P10 corpus attempt remained red after the reader was corrected.
The instrument exposed two independent causes:

```text
qualified_consumer_ablation
network_current_work_deferred_by_inherited_form
```

The first cause is correct. A life grown with `ablate_relation_consumer=true`
is a useful causal experiment but cannot be promotion evidence. The permanent
P10 corpus therefore uses no consumer ablation; the separate ablation test
remains supporting evidence.

The second cause is a classification bug. Deferring current-work observation
while a blocking inherited form is live is the intended treatment order, not
an incomplete or contradictory witness. The diagnostic had no named semantic
reader. Its only effective reader was the global `snapshot.unqualified` check,
which rejected the exact route that established the prerequisite.

Selected correction:

```text
do not write network_current_work_deferred_by_inherited_form as unqualified
do not add a second suppression ledger
derive the ordering from the live inherited-form witness and field state
retain all real incomplete/truncated/unsupported diagnostics unchanged
```

This is not a relaxation for arbitrary diagnostics. It removes one writerless
record whose classification contradicted the treatment that produced it.
