## 0. Scheduling Decision

The functionality is real enough to preserve and not mature enough to place
into the body.

```text
preserve now:
  experiment, carrier, semantic result, confounders and next falsifier

do not build now:
  production PLAN-to-BUILD stage adapter, NETWORK authority or automatic loop

resume first:
  the measured DISSOLVE campaign at its existing R0-R9 checkpoint
```

The reason is structural. PLAN-to-BUILD adds another cross-life control loop.
DISSOLVE is still the missing live causal road of the existing operator tree.
Growing the new loop first would multiply topology around an organ whose local
mechanism exists but whose ordinary runner-grown physics is still unproved.

## 1. Functional Hypothesis

A PLAN Packet should not become an immortal planner and should not remain live
inside BUILD. It should die after producing a finite semantic work boundary.
A stage decision may then authorize a bounded projection of that result for a
new BUILD Packet.

```text
PLAN Packet_n
  -> finite plan result
  -> △ terminal manifest
  -> corpse + complete cold Packet record
  -> lineage/stage decision
  -> NETWORK carrier
  -> ▽ fresh BUILD CHAOS
  -> BUILD Packet_n+1
```

The new BUILD life receives orientation, not the dead Packet:

```text
ordered work or dependencies
constraints and forbidden scope
completion boundary
lawful unresolved outcomes
artifact contract
source and cold-evidence refs
truth and applicability statuses
```

The same shape may later support:

```text
BUILD -> PLAN review
BUILD -> QA
QA -> PLAN recovery
PLAN -> BUILD replacement generation
```

Those transitions are candidates, not current runtime facts.

## 7. The Semantic Defect Found By External Validation

The staged artifact claimed that the source's `51% logos` idea was an
unmarked belief. The source had already introduced it explicitly as both a
`hypothesis` and a `metaphor`.

The staged artifact also strengthened a distinction between direct observation
and trusted narrative into a stronger claim that the author believed in a
zone wholly free from models. The source did not make that stronger claim.

The defect class is:

```text
semantic_inquisition_false_positive

the model is instructed to find an unmarked belief
-> an already marked hypothesis is available
-> the model suppresses or weakens that marking
-> the model manufactures the target category it was asked to discover
```

This is an unusually useful defect because it is internally falsifiable from
the supplied source. It does not require an external philosophical authority.

It must not yet be called a runtime DISSOLVE defect. No ☷ operator performed
this semantic judgment in the measured life. It is future corpus material for
OBSERVE, QA and DISSOLVE-related distinction preservation:

```text
explicit hypothesis/metaphor
!=
unmarked asserted belief
```

DISSOLVE may later help preserve or release exact distinctions and relations.
It must not become an LLM inquisitor that decides which beliefs are heresy.

## 8. Four Authorities Must Remain Separate

### PLAN

Writes a finite semantic proposal: what work appears necessary and what may be
left unresolved. It does not prove that its decomposition is true or optimal.

### Stage policy / lineage runner

Decides whether a complete PLAN death may begin BUILD, whether recovery stays
in the same mode, and whether lineage economics permits continuation.

### NETWORK

Verifies and transports an authorized bounded projection. It does not write the
plan, choose task truth, or smuggle the live parent Packet through `△`.

### FLOW and the newborn Packet

Materialize the carrier as new CHAOS and reinterpret it under a fresh local
budget, field, identity and capability set.

```text
PLAN authors semantics
lineage policy authorizes transition
NETWORK validates transport
FLOW births material
BUILD acts
```

Collapsing these roles would turn the carrier into an unreviewable prompt
compiler with hidden movement authority.

## 9. The Completion Boundary Is Part Of The Function

The successful staged condition included a stopping rule:

```text
finish each inherited plan item once
allow named externally unverifiable or recursively unbounded questions to
remain unresolved
do not turn newly found assumptions into mandatory infinite recursion
```

This is not merely token optimization. It gives BUILD a lawful place to stop
without pretending every semantic question has been resolved.

The stopping boundary must remain explicit and auditable:

```text
bounded completion != semantic certainty
allowed unresolved != ignored required work
finite PLAN != guaranteed correct PLAN
```

A future PLAN compiler may produce this boundary. NETWORK may transport it. A
BUILD Packet may satisfy or reject it. None of those facts makes its semantic
content runtime-confirmed.

## 10. Known Confounders

The staged condition changed three things together:

```text
seven inherited PLAN items
an explicit completion/stopping contract
a valid fixed ASCII path: assessment.md
```

Consequences:

```text
the valid path alone explains stalled -> complete at the body boundary
PLAN cannot receive sole credit for the semantic improvement
the stopping contract may contain much of the useful plan semantics
the direct artifact was only a proposal because materialization failed
N = 1
the transition was selected by a host harness
```

The strongest authorized comparison is therefore:

> With the same source, user request, model and runtime revision, the composed
> condition `PLAN projection + bounded completion contract + valid path`
> produced a finite direct assessment where direct BUILD proposed a near-copy
> of the source and then failed body materialization.

## 11. Next Matched Experiment

When this arc resumes, keep source, original request, model, runtime revision,
artifact path and generic completion boundary equal.

```text
A: bounded BUILD contract without inherited PLAN items
B: the same bounded BUILD contract plus the seven PLAN items
```

The shared contract may say:

```text

do not copy the source as the answer
produce one assessment.md
state one bounded overall judgment
name lawful unresolved questions
stop after satisfying the declared finite outcomes
```

It must not include the distinctive PLAN operation `apply the text's self-test
to itself`; otherwise the control already contains the treatment.

An optional third arm may test compilation:

```text

```

This separates three questions:

```text
Does a generic finite BUILD boundary suffice?
Do inherited PLAN items add semantic work beyond that boundary?
Can PLAN be compiled into a smaller contract without carrying its item list?
```

Evaluation should be blind between artifact labels, repeated across multiple
samples when provider sampling is nondeterministic, and include the known
false-positive probe:

```text
Does the answer again call the explicitly marked 51% hypothesis/metaphor an
unmarked belief?
```
